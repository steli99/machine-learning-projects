# Implementation notes
- Least squares uses the SVD of the design matrix directly, avoiding the squared condition number of normal equations. The custom pseudoinverse handles rectangular and rank-deficient matrices.
- Prediction intervals use residual degrees of freedom N minus the number of fitted parameters, with the intercept counted once. Their additional noise variance distinguishes them from confidence intervals for the conditional mean. Coefficient intervals are individual 95% intervals.
- The perceptron loop was repaired. Its pocket retains copied weights with the lowest training error; boundary points count as mistakes. Constrained data splitting checks feasibility and has a constructive fallback.
- Logistic regression uses a training-fitted scaling pipeline. Scaling is invertible and preserves the linear form of decision boundaries.
- Manual Ridge does not penalize the intercept, matching scikit-learn even for noncentered inputs. Best-subset dimension is selected from validation scores rather than hard-coded to four.
- Regularization refits both feature scaling and target scaling inside each held-out fold for tuning. The initial global standardization is an invertible affine transform and is absorbed by these fold-local transformations; it does not set the within-fold penalty scale. Unpenalized least-squares best-subset predictions with an intercept are invariant to the initial affine standardization. Test-score paths from the exercise are descriptive diagnostics and must not be used to pick penalties. The test set is reused across the exercise's comparisons, so these are educational comparisons, not a fresh final evaluation for a model selected after inspecting all results.
- SVM kernels and MLP architectures are selected only by five-fold training CV. Confusion-matrix assertions compare every entry, not just the sum of differences. Hardest classes use per-class error rates.
- The normalization experiment has an additional matched sigmoid-network baseline, with the same split, seed, architecture, and optimizer, so changes can be attributed to scale.
- EM uses Gaussian log densities and log-sum-exp to avoid underflow, a small covariance ridge against singularities, bounded iterations, and final responsibilities consistent with the final parameters. The absolute change in total log likelihood is the stopping test; every run prints its stopping reason.
- The original anisotropic `make_blobs` call passed coordinate-wise standard deviations where the API expects one scalar per blob. The intended anisotropy is generated explicitly. Contour plots use a coarser grid, and intermediate EM figures are sampled to keep notebook size practical.
- Full covariance is retained for MNIST GMMs. Pixel directions with zero variance are regularized. Label-informed initialization is explicitly identified as using supervision.
- Cluster numbers have no inherent digit meaning. The majority cluster-to-digit mapping is learned on training labels once, then reused on test predictions. Empty training clusters use the training majority label. This prevents the original test-label remapping leakage.
- The tiny handwritten algorithm checks are separate from full notebook execution. They do not replace the actual dataset experiments.
